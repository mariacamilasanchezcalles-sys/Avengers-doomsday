# Fotos del maratón

Sube aquí las fotos (JPG, PNG o WebP) y aparecerán solas en la pestaña **Fotos** de la página.

- Para agruparlas, crea una carpeta por película o tema, por ejemplo `01 X-Men/`.
  El número del inicio solo sirve para ordenar; en la página se ve "X-Men".
- Para ponerle un texto a una foto, agrega un archivo `.txt` con el mismo nombre
  (por ejemplo `selfie.jpg` y `selfie.txt`).
- No edites `fotos.json` ni la carpeta `_mini`: los genera GitHub automáticamente.
- ⚠️ La página es pública: cualquiera con el enlace puede ver estas fotos.
